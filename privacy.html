북메이트 개인정보처리방침

시행일: 2026년 10월 3일 (이전 판: 2026년 8월 23일 베타)
한 줄 요약 — 북메이트는 계정이 없고, 문장과 독서 기록은 사용자 기기 안에만 저장됩니다. 다른 이용자에게 보이는 닉네임과 방 정보만 서버를 거치며, 방은 7일 뒤 자동으로 지워집니다.

1. 수집하지 않는 정보

북메이트는 회원가입과 로그인이 없고, 이름, 이메일, 전화번호, 위치, 기기 식별자를 수집하지 않습니다.

2. 기기에만 저장되는 정보

다음 정보는 사용자 기기의 로컬 저장소(localStorage)에만 저장되며, 운영자를 포함한 누구에게도 전송되지 않습니다.

  • 남긴 문장과 책 이름
  • 독서 세션 기록(횟수, 시각, 읽은 시간)
  • 알림 설정, 숨긴 사용자 목록, 이용 규칙 동의 여부

앱의 "기록 전체 삭제" 버튼, 앱 삭제, 브라우저 데이터 삭제로 언제든 완전히 지울 수 있습니다.

3. 서버로 전송되는 정보

함께 읽기 기능을 위해 아래 정보가 실시간 서버(Supabase)를 거칩니다.

  • 지금 읽는 중 표시: 닉네임, 접속 상태, 접속마다 새로 만드는 임의 번호. 세션이 끝나거나 앱을 닫으면 사라지며 데이터베이스에 저장되지 않습니다.
  • 내가 연 방: 방 이름, 날짜, 시작 시각, 닉네임. 모든 이용자에게 당일 시간표로 보이고, 7일 뒤 자동 삭제됩니다.
  • 신고: 신고 대상(방 번호 또는 닉네임)과 사유. 신고한 사람의 정보는 담기지 않으며, 90일 뒤 자동 삭제됩니다.

닉네임과 방 이름은 다른 이용자에게 보이므로 실명, 연락처 등 개인을 알아볼 수 있는 정보는 넣지 말아 주세요.

4. 이용하는 외부 서비스

  • Supabase(실시간 중계와 방 저장, 서버 위치: 대한민국 서울(AWS ap-northeast-2))
  • GitHub Pages(앱 화면 제공)
  • jsDelivr(앱이 쓰는 공개 라이브러리 제공)

이 서비스들은 요청을 처리하는 과정에서 접속 IP 주소 등 기술 기록을 자체 정책에 따라 일시 보관할 수 있습니다. 북메이트는 광고, 분석, 추적 도구(쿠키, 픽셀, 애널리틱스)를 쓰지 않으며, 정보를 판매하거나 제3자에게 제공하지 않습니다.

5. 이용 연령

북메이트는 만 14세 이상을 대상으로 합니다.

6. 삭제 요청과 신고

내가 연 방을 7일 전에 지우고 싶거나, 부적절한 방이나 닉네임을 발견하면 앱의 신고 버튼 또는 아래 이메일로 알려 주세요. 확인 후 지체 없이 삭제합니다.

7. 방침 변경

수집 항목이 바뀌는 경우 이 문서를 먼저 갱신하고 앱 안에 알린 뒤 적용합니다.
